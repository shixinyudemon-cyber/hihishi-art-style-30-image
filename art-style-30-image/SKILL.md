# 30种图片风格

本 Skill 只负责把用户的内容要求与这套风格预设结合，并检查结果。实际出图和修图沿用可用的 `imagegen` Skill 与图片工具；不要另建生成脚本或擅自换成付费服务。若图片工具不可用，说明情况，可交付提示词，但不得声称已出图。视频请求不属于本 Skill。

## 使用方式

1. 从用户话语中提取主体、动作或场景、用途、画幅、指定风格、必须保留和必须避免的内容。用户指定编号或名称时，按 [风格表](references/styles.md) 对应项执行；没有指定而要求推荐时，按用途和主体推荐最多3种并说明差别。不要用推荐结果覆盖明确指定的风格。
2. 把风格表中的视觉特征加到用户原本的画面要求上。风格控制表现方式，不替换主体、情节或用途。图中原有的示例场景与16:9比例都不是默认要求。风格名称本身不足以控制效果时，用媒介、笔触或结构、材质、色彩与光照等具体特征描述。02“像素艺术”默认采用风格表中的明亮、层次丰富方向；只有用户明确要求“老游戏”“8位”等时才使用更粗像素、更简化的变体。
3. 区分参考图的角色：主体参考、构图参考、风格参考或编辑对象。用户只提供风格参考时生成新图；用户要求保留原图并改变画风时按编辑处理。原始的十张汇总图片含排版和文字，不应直接作为成图或在新图里重现其标题、水印、说明框。
4. 用户要求直接出图时，按 `imagegen` 的当前工作流程调用内置图片工具；用户只要提示词时，仅交付可复制的提示词。多种风格比较时，固定主体及关键构图，每种风格分别出图或分别给提示词。不要未经要求批量生成30张。
5. 实际出图后查看结果，至少核对主体、指定风格的关键特征、画幅、文字和保留项。只针对看到的偏差提出或执行有针对性的修订；不能把提示词完成当成图片效果已验证。

## 边界

- 风格表是重新整理的视觉特征，不把用户提供的示例图片或其整段文案打包、传播或当成每次的固定提示词。若用户要求高度贴合某张示例图，先确认该图在当前对话可见，并说明它只作为风格参考。
- 对于“废土末日”“赛博东方”等题材型风格，优先保留用户指定的主体；只借用相容的世界观、材质和色彩。对于“建筑摄影”等用途型风格，若主体明显不适合，应说明适配方式或给出更合适的风格选择。
- 不承诺像素级复刻、绝对角色一致或模型不支持的参数。图片工具的能力和保存规则以当前 `imagegen` Skill 为准。

## 调用例子

- “用14号剪纸艺术画一只小狗在竹林里跑，竖版封面，不要文字。”
- “同一只猫坐在窗边，用02像素艺术和06黏土艺术各做一张，构图尽量一致。”
- “我要做儿童绘本封面，从这30种里推荐3种，先不要出图。”
