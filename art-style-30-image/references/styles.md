# 30种风格速查

此表从用户提供的十张风格图提炼。编号与中文名称保持对应；以下是可迁移的视觉特征，不包含原示例场景或固定画幅。混合风格时先遵从用户明确的主风格。

| 编号 | 风格 | 出图时的核心特征 |
| --- | --- | --- |
| 01 | 电影写实 | 真实摄影质感、可信的物理光线与材质、镜头构图、自然景深和环境细节；避免插画感与过度CG感。 |
| 02 | 像素艺术 | 默认采用明亮而丰富的色彩、清晰可辨但不过分粗大的像素块、阶梯轮廓、前中后景层次；主体要突出，避免重复建筑过密、平滑矢量边缘和照片纹理。不要默认压缩成极简老游戏画面。 |
| 03 | 中国水墨 | 墨色浓淡、笔触皴擦、宣纸渗化、大面积留白和虚实层次；避免厚重西式油彩。 |
| 04 | 古典写实油画 | 严谨造型、细腻油画笔触、深沉综合色调、体积光和画布肌理。 |
| 05 | 废土末日 | 破败设施、风化与锈蚀、尘土、低饱和大地色及严酷自然光；根据主体需要控制荒凉程度。 |
| 06 | 黏土艺术 | 手工捏塑形体、可见的黏土表面与轻微不规则、柔和光线、实体微缩模型感。 |
| 07 | 赛博东方 | 东方建筑或装饰语汇与未来科技并置，金属、玻璃、霓虹、潮湿反光和层叠城市空间。 |
| 08 | 浮世绘 | 平涂色块、清晰墨线、木版套印感、装饰性轮廓与传统版画构图；弱化摄影透视。 |
| 09 | 毛毡手作 | 羊毛纤维、针刺肌理、圆润手工形体、柔软边缘和微缩实物拍摄感。 |
| 10 | 暗黑哥特 | 尖拱、繁复雕饰、深色石材、烛光或冷光、浓重阴影与压迫氛围；不必强加宗教物件。 |
| 11 | 波普艺术 | 大胆轮廓、高饱和撞色、网点和印刷颗粒、平面图形与商业海报般的视觉冲击。 |
| 12 | 低多边形 | 可见多边形切面、硬边几何结构、块面明暗、简化的三维造型；避免光滑高精度曲面。 |
| 13 | 超现实主义 | 写实元素的不合常理组合、尺度错位、梦境逻辑与视觉矛盾；保持画面内部的质感统一。 |
| 14 | 剪纸艺术 | 精细纸张切边、镂空、层叠纸片和投影，有限配色与强装饰性轮廓。 |
| 15 | 钩针编织 | 可辨的针脚、毛线纤维和编织纹路，柔软立体形体与真实手工质感；区别于毛毡。 |
| 16 | 复古未来主义 | 中世纪未来想象、流线型与圆顶、复古金属和奶油色系，乐观的太空时代设计语言。 |
| 17 | 表现主义 | 夸张或扭曲造型、激烈笔触、主观情绪主导的色彩和空间；不追求摄影准确性。 |
| 18 | 纸雕艺术 | 纸板切割、折叠与层叠形成的实体结构，可见纸张厚度、纤维、镂空和柔和投影；区别于平面剪纸。 |
| 19 | 商业建筑摄影 | 建筑尺度与空间秩序、准确的垂直线和材质、克制构图、自然或专业建筑照明。 |
| 20 | 印象派 | 松散短笔触、光色变化、空气感和瞬间观感，保留画布与颜料质地。 |
| 21 | 等距3D | 稳定的等距或近等距视角、清晰模块化三维结构、可读的空间布局与统一比例。 |
| 22 | 生物机械 | 生物组织与机械结构融合，金属骨架、关节、湿润有机表面和精细连接；避免无理由堆砌管线。 |
| 23 | 工笔重彩 | 细密白描线、层层设色、矿物颜料般的浓丽色彩与装饰性图案，造型精谨。 |
| 24 | 刺绣艺术 | 布料底纹、丝线针脚、线的方向和轻微浮起，轮廓与明暗由绣线组织；区别于钩针。 |
| 25 | 故障艺术 | 通道错位、扫描线、压缩痕迹、数据撕裂和数字色彩干扰；主体仍应可辨。 |
| 26 | 敦煌壁画 | 古壁画基底、矿物色、传统线描与装饰纹样，适度剥落和历史沉积感；避免把不同历史元素随意混成具体文物复刻。 |
| 27 | 3D卡通 | 圆润夸张的三维造型、柔和材质、协调明快的配色、清晰表情与动画电影式光照。 |
| 28 | 拼贴艺术 | 照片、旧纸、地图或印刷碎片的裁切重组，撕边、重叠、胶痕与异质材料关系。 |
| 29 | 孟菲斯 | 不规则几何、鲜明撞色、波浪线与点状图案，平面与立体元素混搭的活泼设计感。 |
| 30 | 几何抽象 | 圆、矩形、三角、弧线与纯色色块，通过比例、重叠、留白和节奏组织画面。 |

02 的“老游戏”变体仅在用户明确提出时使用：建筑和背景进一步简化，像素颗粒更粗，颜色更少。它不是02的默认效果。
