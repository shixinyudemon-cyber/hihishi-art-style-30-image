# 30 种图片风格 Skill

本仓库提供 30 种图片风格的 Codex Skill、风格说明和原创示例图，并标明各部分的授权方式。

## 包含内容

- `art-style-30-image/SKILL.md`：Codex Skill 的使用规则。
- `art-style-30-image/references/styles.md`：30 种风格的可迁移视觉特征。
- `art-style-30-image/examples/`：30 张示例图，每种风格一张，统一主题为“狐狸放蓝色风筝”。

## 授权范围

- Skill 的文字、风格表和本说明按 [MIT License](LICENSE) 开放。复制或分发时，须保留版权与许可声明；对外署名为 **hihi.Shi**。
- `examples/` 中的 30 张 PNG 按 [CC BY 4.0](art-style-30-image/examples/LICENSE.md) 开放，具体以该目录的授权说明为准。分享或改图时，须注明 **hihi.Shi**、附上许可链接，并说明是否修改。
- 原始十张参考图不在此包中，也不受上述授权声明覆盖。别人使用这个 Skill 生成的新图，同样不会自动受到本包的许可约束。

示例图是 AI 生成的风格展示，没有收录用户提供的十张参考图、其排版或整段提示词。第 19 张采用修订版，其余图片采用各风格已选定的版本。

## 本地使用

将 `art-style-30-image` 文件夹放进 Codex 的 Skills 目录后，可以说：

> 用 14 号剪纸艺术画一只小狗在竹林里跑，横版，不要文字。

也可以只要求推荐风格或只要提示词。实际出图仍需可用的图片生成工具；这个 Skill 本身不包含图片生成模型。
